# Cardinal Acoustics has moved

The Cardinal and BROOKS projects now live with the rest of the field-site work at
**[github.com/carbonranch](https://github.com/carbonranch)**.

- Cardinal, acoustic localization of birds from small recorder arrays: [carbonranch/cardinal](https://github.com/carbonranch/cardinal)
- BROOKS, an unsupervised inventory of orthopteran song: [carbonranch/brooks](https://github.com/carbonranch/brooks)

Links to the former `cardinal-acoustics/cardinal` and `cardinal-acoustics/brooks` addresses, including those in the
Cardinal preprint, redirect to the new locations.
